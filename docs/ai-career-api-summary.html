AI Career Matching Platform - Proje Ozeti

Bu belge, AI Career Matching uygulamasinda su ana kadar gelistirilen backend, frontend, veritabani, API, kullanici arayuzu ve gelistirici akisi ozelliklerini ozetler.

1. Backend Altyapisi

  • Express.js tabanli API projesi kuruldu.
  • Swagger API dokumantasyonu eklendi.
  • MongoDB baglantisi MONGO_URI uzerinden calisiyor.
  • JWT tabanli register/login akisi eklendi.
  • POST /api/auth/register, POST /api/auth/login ve /api-docs public kalir.
  • GET /api/health dahil diger tum /api/* endpointleri JWT token ister.
  • Adzuna API baglantisi yapildi.
  • .env ile gizli bilgiler yonetiliyor.
  • Backend adresi: http://localhost:5001
  • Swagger adresi: http://localhost:5001/api-docs

2. Job Ozellikleri

  • Adzuna API'den gercek is ilanlari cekilebiliyor.
  • Cekilen is ilanlari MongoDB'ye kaydediliyor.
  • Duplicate kontrolu title + company uzerinden yapiliyor.
  • backend/models/Job.js ile Job modeli olusturuldu.
  • GET /api/jobs/fetch endpoint'i eklendi.
  • GET /api/jobs/filter endpoint'i eklendi.
  • POST /api/jobs/import-adzuna endpoint'i eklendi.
  • Job filtreleme artik hard-coded veriyle degil, gercek MongoDB verisiyle calisiyor.
  • Filtreleme parametreleri arasinda keyword, skill, minMatch, sort, cvId bulunuyor.

3. CV Ozellikleri

  • backend/models/CV.js ile CV modeli olusturuldu.
  • POST /api/cvs ile CV olusturulabiliyor.
  • GET /api/cvs ile login olan kullanicinin CV listesi alinabiliyor.
  • PUT /api/cvs/:id ile CV guncellenebiliyor.
  • DELETE /api/cvs/:id ile CV silinebiliyor.
  • CV bilgileri MongoDB'ye kaydediliyor.
  • CV id'si ile job match score hesaplanabiliyor.

4. Matching Sistemi

  • POST /api/match endpoint'i eklendi.
  • CV skills ve job skills karsilastiriliyor.
  • Match score hesaplanıyor.
  • Level degeri uretiliyor: Low, Medium, High.
  • Eslesen skill'ler ve eksik skill'ler donduruluyor.
  • Explainability alani guclendirildi.

5. Recommendation Sistemi

  • Recommendation endpoint'i once manuel calisiyordu.
  • Daha sonra gercek MongoDB verisine baglandi.
  • GET /api/recommendations?cvId=... endpoint'i eklendi.
  • CV MongoDB'den cekiliyor ve login olan kullaniciya ait olup olmadigi kontrol ediliyor.
  • Job kayitlari MongoDB'den cekiliyor.
  • CV skills ile job skills karsilastirilip en iyi isler oneriliyor.
  • En iyi 5 oneri donduruluyor.

6. Best CV Ozelligi

  • GET /api/best-cv/:jobId endpoint'i eklendi.
  • Job MongoDB'den cekiliyor.
  • Login olan kullanicinin CV kayitlari MongoDB'den cekiliyor.
  • Ilgili job icin en iyi CV bulunuyor.
  • En iyi CV ve skor donduruluyor.

7. Analysis Ozelligi

  • POST /api/analysis endpoint'i eklendi.
  • Eksik skill'lere gore ogrenme roadmap'i olusturuluyor.
  • Ornek cikti: Learn Docker basics -> practice -> build project

8. Analytics Placeholder Endpointleri

  • GET /api/analytics/skills endpoint'i kullanicinin CV'leri ve global Job verisi uzerinden eksik skill dagilimi donduruyor.
  • GET /api/analytics/trends endpoint'i Adzuna market verisi veya MongoDB job verisi uzerinden trend ozeti donduruyor.
  • Frontend tarafinda Chart.js ile analytics grafik panelleri gosteriliyor.

9. Skill Extractor Servisi

  • backend/services/skillExtractor.js olusturuldu.
  • Job description icinden skill yakalama yapiliyor.
  • Desteklenen ornek skill'ler: Java, SQL, React, Node, Docker, Python.

10. Frontend Altyapisi

  • React ve Vite kuruldu.
  • Frontend adresi: http://localhost:5173
  • Backend adresi: http://localhost:5001
  • Vite proxy ile /api istekleri backend'e yonlendiriliyor.
  • Frontend stilleri Tailwind utility class yapisina tasindi.
  • styles.css yalnizca Tailwind import ve global/base stilleri tutar.

11. Frontend Sayfalari

  • Overview
  • CV Studio
  • Job Explorer
  • AI Insights
  • My Account

12. Kullanici Kayit ve Giris Akisi

  • Site acildiginda kullaniciya Sign Up / Sign In ekrani geliyor.
  • Kayit icin first name, last name, email, password ve telefon bilgisi aliniyor.
  • Telefon alaninda ulke kodu secimi bulunuyor.
  • Kullanici register/login akisi backend auth endpointleri uzerinden calisiyor.
  • Frontend JWT token'i localStorage'da sakliyor; profil ve Career Passport verileri MongoDB'de tutuluyor.

13. Career Passport

  • Kullanicinin genel profesyonel profili olarak tasarlandi.
  • Kayit sonrasi kullanici Career Passport formuna yonlendiriliyor.
  • Skip now butonu ile form sonra doldurulabiliyor.
  • Form daha duzenli olmasi icin bolumlere ayrildi.
  • Bolumler: Career Direction, Education, Skills & Interests, Experience & Proof, Links.
  • Alanlar: target role, location, work style, availability, salary expectation, school, department, graduation year, GPA, skills, tools, languages, interests, experience, projects, certificates, achievements, about me, portfolio, LinkedIn, GitHub.

14. My Account Sayfasi

  • Sag ustte hesap butonu eklendi.
  • My Account sayfasi tasarlandi.
  • Kullanici bilgileri duzenlenebiliyor.
  • Profil fotografi avatar uzerindeki edit kontrolu ile degistirilebiliyor.
  • Career Passport duzenleme islemi modal pencere icinde aciliyor.
  • Modal acildiginda arka plan bulanıklastiriliyor.

15. UI / UX Iyilestirmeleri

  • Ilk basit arayuz modern dashboard yapisina donusturuldu.
  • Sidebar navigasyon eklendi.
  • Dashboard metrikleri eklendi.
  • Job sonuc kartlari eklendi.
  • Recommendation listesi eklendi.
  • Match explanation ve roadmap panelleri olusturuldu.
  • Career Passport formu daha duzenli hale getirildi.
  • My Account sayfasi daha estetik hale getirildi.

16. Uygulamanin Su An Yapabildikleri

  • Kullanici kayit ve giris akisi sunar.
  • Kullanici profesyonel profili olusturabilir.
  • CV olusturabilir, listeleyebilir, guncelleyebilir ve silebilir.
  • Adzuna'dan gercek job verisi cekebilir.
  • Job verilerini MongoDB'ye kaydedebilir.
  • CV'ye gore job filtreleyebilir.
  • CV'ye gore job onerileri olusturabilir.
  • Bir job icin en iyi CV'yi bulabilir.
  • Skill match score hesaplayabilir.
  • Eksik skill'lere gore ogrenme plani olusturabilir.
  • Tum temel akislar React arayuzunden kullanilabilir.

17. Guncel Gelistirici Akisi

  • .env.example tek environment template olarak kullaniliyor.
  • npm run server backend'i baslatir.
  • npm run client frontend'i baslatir.
  • npm run seed:demo demo CV kaydini olusturur veya gunceller.
  • npm run check:db opsiyonel olarak MongoDB baglantisini kontrol eder.
  • Tailwind CSS pipeline ve Chart.js frontend analytics icin kuruludur.
