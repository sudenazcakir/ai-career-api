AI Career Matching Platform - Project Summary

This document summarizes the backend, frontend, database, API, and developer workflow features currently implemented in the AI Career Matching project.

1. Backend Foundation

  • Express.js based API project is set up.
  • Swagger API documentation is enabled.
  • MongoDB connection uses MONGO_URI.
  • Adzuna API integration is available.
  • Environment variables are managed with .env.
  • Backend address: http://localhost:5001
  • Swagger address: http://localhost:5001/api-docs

2. Job Features

  • Jobs can be fetched from Adzuna.
  • Fetched jobs can be saved into MongoDB.
  • Duplicate control is based on title + company.
  • models/Job.js defines the Job model.
  • GET /api/jobs/fetch imports remote jobs.
  • GET /api/jobs/filter supports filtering and sorting.
  • Filtering works on MongoDB data instead of hard-coded data.

3. CV Features

  • models/CV.js defines the CV model.
  • POST /api/cvs creates a CV.
  • GET /api/cvs lists CVs.
  • PUT /api/cvs/:id updates a CV.
  • DELETE /api/cvs/:id deletes a CV.
  • CV records are stored in MongoDB.

4. Matching

  • POST /api/match compares CV skills and job skills.
  • Returns match score, level, matching skills, missing skills, and explanation.
  • GET /api/best-cv/:jobId finds the best CV for a stored job.

5. Recommendations

  • GET /api/recommendations?cvId=... ranks jobs using a stored CV.
  • The endpoint reads both CV and Job data from MongoDB.
  • The best 5 recommendations are returned.

6. Analysis

  • POST /api/analysis creates a learning roadmap from missing skills.
  • Example output: Learn Docker basics -> practice -> build project

7. Analytics Placeholder Endpoints

  • GET /api/analytics/skills is available as a placeholder endpoint.
  • GET /api/analytics/trends is available as a placeholder endpoint.
  • Both endpoints currently return empty future-ready analytics payloads.

8. Skill Extractor Service

  • services/skillExtractor.js extracts known skills from job descriptions.
  • Example supported skills: Java, SQL, React, Node, Docker, Python.

9. Frontend Foundation

  • React and Vite are configured.
  • Frontend address: http://localhost:5173
  • Backend address: http://localhost:5001
  • Vite proxy forwards /api calls to the backend.

10. Frontend Pages

  • Overview
  • CV Studio
  • Job Explorer
  • AI Insights
  • My Account

11. Demo User Flow

  • Users see Sign Up / Sign In on first load.
  • Demo user data is stored in localStorage.
  • Career Passport onboarding can be filled or skipped.
  • Professional profile data can be edited later from My Account.

12. Current Developer Workflow

  • .env.example is the single environment template.
  • npm run server starts the backend.
  • npm run client starts the frontend.
  • npm run seed:demo creates or updates a demo CV.
  • npm run check:db optionally verifies MongoDB connectivity.
