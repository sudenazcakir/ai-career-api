AI Career Matching Platform - Project Summary

Bu belge, AI Career Matching uygulamasında şu ana kadar geliştirilen backend, frontend, veritabanı, API ve kullanıcı arayüzü özelliklerini özetler.

1. Backend Altyapısı

  • Express.js tabanlı API projesi kuruldu.
  • Swagger API dokümantasyonu eklendi.
  • MongoDB Atlas bağlantısı yapıldı.
  • Adzuna API bağlantısı yapıldı.
  • .env ile gizli bilgiler yönetiliyor.
  • Backend adresi: http://localhost:5001
  • Swagger adresi: http://localhost:5001/api-docs

2. Job Özellikleri

  • Adzuna API'den gerçek iş ilanları çekilebiliyor.
  • Çekilen iş ilanları MongoDB'ye kaydediliyor.
  • Duplicate kontrolü title + company üzerinden yapılıyor.
  • models/Job.js ile Job modeli oluşturuldu.
  • GET /api/jobs/fetch endpoint'i eklendi.
  • GET /api/jobs/filter endpoint'i eklendi.
  • Job filtreleme artık hard-coded veriyle değil, gerçek MongoDB verisiyle çalışıyor.
  • Filtreleme parametreleri: keyword, skill, minMatch, sort, cvId.

3. CV Özellikleri

  • models/CV.js ile CV modeli oluşturuldu.
  • POST /api/cvs ile CV oluşturulabiliyor.
  • GET /api/cvs ile CV listesi alınabiliyor.
  • CV bilgileri MongoDB'ye kaydediliyor.
  • CV id'si ile job match score hesaplanabiliyor.

4. Matching Sistemi

  • POST /api/match endpoint'i eklendi.
  • CV skills ve job skills karşılaştırılıyor.
  • Match score hesaplanıyor.
  • Level değeri üretiliyor: Low, Medium, High.
  • Eşleşen skill'ler ve eksik skill'ler döndürülüyor.
  • Explainability alanı güçlendirildi.

5. Recommendation Sistemi

  • Recommendation endpoint'i önce manuel çalışıyordu.
  • Daha sonra gerçek MongoDB verisine bağlandı.
  • GET /api/recommendations?cvId=... endpoint'i eklendi.
  • CV MongoDB'den çekiliyor.
  • Job kayıtları MongoDB'den çekiliyor.
  • CV skills ile job skills karşılaştırılarak en iyi işler öneriliyor.
  • En iyi 5 öneri döndürülüyor.

6. Best CV Özelliği

  • GET /api/best-cv/:jobId endpoint'i eklendi.
  • Job MongoDB'den çekiliyor.
  • Tüm CV kayıtları MongoDB'den çekiliyor.
  • İlgili job için en iyi CV bulunuyor.
  • En iyi CV ve skor döndürülüyor.

7. Analysis Özelliği

  • POST /api/analysis endpoint'i eklendi.
  • Eksik skill'lere göre öğrenme roadmap'i oluşturuluyor.
  • Örnek çıktı: Learn Docker basics -> practice -> build project

8. Skill Extractor Servisi

  • services/skillExtractor.js oluşturuldu.
  • Job description içinden skill yakalama yapılıyor.
  • Desteklenen örnek skill'ler: Java, SQL, React, Node, Docker, Python.

9. Frontend Altyapısı

  • React ve Vite kuruldu.
  • Frontend adresi: http://localhost:5173
  • Backend adresi: http://localhost:5001
  • Vite proxy ile /api istekleri backend'e yönlendiriliyor.

10. Frontend Sayfaları

  • Overview
  • CV Studio
  • Job Explorer
  • AI Insights
  • My Account

11. Kullanıcı Kayıt ve Giriş Akışı

  • Site açıldığında kullanıcıya Sign Up / Sign In ekranı geliyor.
  • Kayıt için first name, last name, email, password ve telefon bilgisi alınıyor.
  • Telefon alanında bayraklı ülke kodu seçimi bulunuyor.
  • Kullanıcı verileri şimdilik localStorage'da saklanıyor.

12. Career Passport

  • Kullanıcının genel profesyonel profili olarak tasarlandı.
  • Kayıt sonrası kullanıcı Career Passport formuna yönlendiriliyor.
  • Skip now butonu ile form sonra doldurulabiliyor.
  • Form daha düzenli olması için bölümlere ayrıldı.
  • Bölümler: Career Direction, Education, Skills & Interests, Experience & Proof, Links.
  • Alanlar: target role, location, work style, availability, salary expectation, school, department, graduation year, GPA, skills, tools, languages, interests, experience, projects, certificates, achievements, about me, portfolio, LinkedIn, GitHub.

13. My Account Sayfası

  • Sağ üstte hesap butonu eklendi.
  • My Account sayfası tasarlandı.
  • Kullanıcı bilgileri düzenlenebiliyor.
  • Profil fotoğrafı avatar üzerindeki kalem simgesiyle değiştirilebiliyor.
  • Career Passport düzenleme işlemi modal pencere içinde açılıyor.
  • Modal açıldığında arka plan bulanıklaştırılıyor.

14. UI / UX İyileştirmeleri

  • İlk basit arayüz modern dashboard yapısına dönüştürüldü.
  • Sidebar navigasyon eklendi.
  • Dashboard metrikleri eklendi.
  • Job sonuç kartları eklendi.
  • Recommendation listesi eklendi.
  • Match explanation ve roadmap panelleri oluşturuldu.
  • Career Passport formu daha düzenli hale getirildi.
  • My Account sayfası daha estetik hale getirildi.

15. Uygulamanın Şu An Yapabildikleri

  • Kullanıcı kayıt ve giriş akışı sunar.
  • Kullanıcı profesyonel profili oluşturabilir.
  • CV oluşturabilir ve listeleyebilir.
  • Adzuna'dan gerçek job verisi çekebilir.
  • Job verilerini MongoDB'ye kaydedebilir.
  • CV'ye göre job filtreleyebilir.
  • CV'ye göre job önerileri oluşturabilir.
  • Bir job için en iyi CV'yi bulabilir.
  • Skill match score hesaplayabilir.
  • Eksik skill'lere göre öğrenme planı oluşturabilir.
  • Tüm temel akışlar React arayüzünden kullanılabilir.
